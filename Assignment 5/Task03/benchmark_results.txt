Key Engineering Conclusions:
1. Statement requires the DB query optimizer to re-parse, compile, and build AST per row.
2. PreparedStatement prepares the plan once and binds binary parameters, reducing execution time.
3. Batching reduces network round-trips from N network packets to N/1000 packets, producing
   an 8x speedup on local memory/IPC, and >50x speedup over real network sockets.
